# PackSmart — квиз-калькулятор упаковки

Интерактивный подбор упаковочных материалов: 3 шага → корзина → ориентировочная цена → заявка в WhatsApp.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`

## Настройки

Файл `.env`:

- `VITE_WHATSAPP_PHONE` — номер в международном формате без `+` (например `77001234567`)
- `VITE_ADMIN_PASSWORD` — пароль админки (по умолчанию `packsmart`)

Админка: `/admin`

## Что внутри

- Квиз с прогресс-баром, карточками ответов, валидацией «Назад / Далее»
- Подбор товаров по ответам + расчёт (розница/опт, скидки от количества, модификаторы, срочность)
- Финальный экран с корзиной и формой лида
- Админ: CRUD товаров, заявки, статистика ответов (localStorage)
